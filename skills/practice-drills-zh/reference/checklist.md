# 质量清单：practice-drills-zh

## 题目设计
- [ ] 每道题只复刻**一个**从业者必须理解的机制，对照固定版本仓库里一个具体的函数。
- [ ] track 从基础到整合排列；题目之间的依赖写明了。
- [ ] 分钟数和难度实事求是（熟手大约一半时间能做完）。

## 代码
- [ ] 参考解的模块 docstring = 完整规范：测试检查的每条规则都写在里面。
- [ ] 参考解的注释讲“为什么”（不变量、顺序、朴素写法会坏在哪、真实代码哪里不同）。
- [ ] `given` 把样板代码挡在学习者的一小时之外。
- [ ] `DRILL_IMPL=solutions ./check.sh all` 全部通过。
- [ ] `./check.sh all` 在**每一道**题上都失败（没有测试能在骨架上通过）。
- [ ] `gen_stubs.py drills.json --check` 通过；骨架保留了签名和 docstring，不含答案。
- [ ] 测试是确定性的、只用 CPU、很快（整套几秒内），并以行为命名。
- [ ] 提示页上列出的每个易错点，都有一个能抓住它的测试。

## 页面
- [ ] 每个提示页都有：题面速览 · 类比 · 图解 · 逐步演示 · 易错点 · L1/L2/L3 · 嵌入的参考解 · 追问与源码链接。
- [ ] 示例和逐步演示里的每个数字都是运行参考解得出的。
- [ ] 知识页讲清了题目需要的领域知识，有图和固定链接，最后有“和练习题的对应关系”表。
- [ ] `build_drills.py --strict` 通过（链接、文件、符号、图的 lint、质量下限）。
- [ ] **`.shots/` 下每张截图都打开看过**；布局改到干净为止。
- [ ] `--links` 通过；PDF 能生成；抽查过几页。
- [ ] 中文平实，没有翻译腔；技术名词保留英文。
